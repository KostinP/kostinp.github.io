Цель работы — разработка архитектуры и программного прототипа образовательной платформы, предоставляющей студентам готовые к работе изолированные лабораторные среды прямо в браузере.

В ходе исследования решены следующие задачи:
1. Проведен сравнительный анализ подходов к виртуализации лабораторных сред (VM, Cloud, Containers), обоснован выбор контейнерной оркестрации на базе Kubernetes как оптимального по изоляции, стоимости и масштабируемости.
2. Разработана модульная архитектура системы, включающая модули аутентификации (OAuth2 через VK/Telegram), управления контентом (курсы/уроки), оркестрации контейнеров (code-server в подах) и аналитики.
3. Реализован бэкенд-сервер на Go с использованием принципов Clean Architecture и Domain-Driven Design, обеспечивающий высокую производительность и поддерживаемость кода.
4. Разработана система контроля доступа на основе атрибутов (ABAC), заменяющая классическую RBAC для гибкого управления правами преподавателей и студентов в контексте конкретных курсов.
5. Создан клиентский интерфейс на Next.js с интеграцией веб-IDE (code-server), позволяющий студентам выполнять задания без локальной настройки окружения.
6. Реализован пайплайн непрерывной доставки (GitLab CI/CD → Docker → Kubernetes) с GitOps-подходом (ArgoCD) для автоматизации развертывания.

Созданный прототип успешно прошел функциональное тестирование, включая сценарий создания курса преподавателем, запуска лабораторного пода (code-server) студентом, выполнения практического задания и отправки результата через GitHub. Архитектура позволяет доработать модуль для полноценного production-использования в университетской среде.
